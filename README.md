# signlanguage_recognition

## Dataset

This project uses the [ASL Alphabet dataset](https://www.kaggle.com/datasets/grassknoted/asl-alphabet) from Kaggle. The data is not included in this repo.

1. Download the dataset from the link above.
2. Upload it to your Google Drive at `MyDrive/SignLanguageDetection/`.
3. Open the notebook in Colab and run the cells. The `DATA_DIR` path in the notebook should match your folder.
